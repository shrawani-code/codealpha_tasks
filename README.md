# CodeAlpha Internship Tasks

This repository contains the projects completed as part of my CodeAlpha Artificial Intelligence Internship.

## Projects

### 1. AI FAQ Chatbot

A Python-based FAQ chatbot using Natural Language Processing, TF-IDF, cosine similarity, and Streamlit.

**Technologies:** Python, NLP, NLTK, Scikit-learn, Streamlit

### 2. AI Object Detection & Tracking

An object detection and tracking application built using YOLO and Streamlit. It can detect objects in images and track objects in video.

**Technologies:** Python, YOLO, Ultralytics, OpenCV, Streamlit
